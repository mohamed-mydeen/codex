# Attendance Tracker PWA

A free, offline-first React/Vite attendance tracker for personal and college use. The app stores all data locally in `localStorage` and includes subject management, attendance history with undo, timetable, calculator, backup/restore, dark mode, and PWA offline support.

## Development

```bash
npm install
npm run dev
npm run build
```

No backend, authentication, cloud database, analytics, ads, or external API calls are used by the application.
